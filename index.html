能做什么

一台会自己
动手的手机

为移动场景重新设计的 DSH 运行时：轻、快、稳，动作都在本机发生。

真机 Agent 任务

一句话下发，手机自己动手：点击、输入、滑动、跨应用跳转，全部在本机执行，不上传屏幕。

想、说、计划、做

先推演再开口，多步骤先列清单，做完一条看结果再决定下一步；点错了会承认并换路。

纯文字输出

结果用自然语言分点说清，不塞表格、不甩过程垃圾；数字与单位照屏幕原样。

流式对话

逐字输出、思考过程可展开，长回答不卡顿，随时中断、随时续写。

工具调用可视

文件读写、检索、多步骤任务的调用链路全程可见，过程透明，可随时叫停。

离线 OCR

中文识别模型随包内置，飞行模式照样读屏，截图与文字始终不出设备。

插件系统

核心能力锁定常驻，美化与娱乐插件自由开关、即点即生效，关掉即零开销。

会话与工作区

直接访问本机文件目录，配合精细权限管理；会话、配置全部留在设备上。

安全存储

密钥与会话凭据经 Android Keystore 加密保存，卸载即销毁。

常见问题

安装时提示「未知来源」怎么办？

这是 Android 对非应用商店安装包的标准提示。在系统弹窗中选择「允许」即可；部分机型需要在「设置 → 应用 → 特殊权限 → 安装未知应用」中放行你的浏览器或文件管理器。

应用会收集我的数据吗？

本应用不内置任何数据采集。会话记录与配置仅保存在你的设备本地，凭据经系统级加密存储。详见应用内「关于 → 隐私政策」。

工作模式为什么要求无障碍权限？

Agent 要在真机上点击、输入、滑动，只能通过系统的无障碍服务完成，这也是唯一不 Root 的合法路径。权限只用于你下发的任务，屏幕内容不会上传；覆盖安装新版本后系统会自动关闭该服务，需要再开一次。

如何检查更新？

打开应用「设置 → 关于 → 检查更新」，应用读取管理端版本接口并在 App 内下载、校验后引导安装，不会跳转官网或打开浏览器；也可以直接在本页手动下载最新 APK 覆盖安装。

与 DeepSeek 官方是什么关系？

本应用为独立开发的 DSH-Move 移动客户端，与 DeepSeek 官方无隶属关系；相关名称与标识归其权利人所有。
